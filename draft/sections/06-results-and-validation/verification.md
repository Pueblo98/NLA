### Solver counts: deduplicate numeric systems, not key strings

`objects_solvers.csv` has **288 case/method rows**, including reused systems. Parse `system_key` with `ast.literal_eval` before deduplicating `(system_key, method)`: numeric-equivalent tuples contain both integer and float spellings. Deduplicating raw strings incorrectly gives 33 systems/264 pairs. Parsed tuples give **27 systems and 216 method/system pairs**; reused rows agree on all performance/status fields.

| Method | Accepted | Other exported outcomes |
|---|---:|---|
| CG | 27 | none |
| Diagonal PCG | 27 | none |
| MINRES | 27 | none |
| Full GMRES | 27 | none |
| Gauss–Seidel | 2 | 25 at iteration cap |
| Steepest descent (SD) | 2 | 25 at iteration cap |
| Damped Jacobi | 0 | 27 at iteration cap |
| Jacobi | 0 | 27 diverged |

Total **112/216** accepted. The original error was **steepest descent**, not the two accepted Gauss–Seidel runs. Both methods succeed on the coarsest square and coarsest perforated square (`a=0.005`). GS uses **6264/6897** iterations, SD **16898/16946**. Their true relative residuals are respectively **9.9937408151e-9/9.9949694757e-9** and **9.9911608008e-9/9.9893087485e-9**, all strictly below the target. Nonaccepted runs are not times to accuracy.

PCG takes fewer iterations on every distinct system but is slower than CG in **26/27** exported best-of-three comparisons. On the finest rectangle it takes **0.0916805830 s**, versus CG's **0.0921728330 s**, a ratio of **0.9946594893**, about **0.5% faster**. This corrects the blanket no-timing-improvement claim without implying a meaningful general speed advantage. No cross-machine timing comparison is made.

Minimal recount, with `root` pointing to the pinned PR 11 results directory:

```python
import ast, csv
from collections import Counter
from pathlib import Path
root = Path('/home/kleon/school/nla-pr11-update/notebook/outputs/results')
rows = list(csv.DictReader((root / 'objects_solvers.csv').open()))
unique = {}
for r in rows:
    key = (ast.literal_eval(r['system_key']), r['method'])
    if key in unique:
        assert all(r[f] == unique[key][f]
                   for f in r if f not in ('case_id', 'system_key'))
    unique[key] = r
assert len(unique) == 216
assert len({key[0] for key in unique}) == 27
assert sum(r['accepted'] == 'True' for r in unique.values()) == 112
print(Counter((r['method'], r['accepted'], r['native_status'])
              for r in unique.values()))
```
