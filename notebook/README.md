# Group 02 notebook

`Group02_Notebook.ipynb` is the self-contained notebook that accompanies `Group02_Report.pdf`. It rebuilds every number, table and figure in the report from scratch:

| Part | Content | Report |
|---|---|---|
| 1–2 | Plane-stress model, P1 triangles, assembly of K, loads, supports, reduced SPD system A x = b | §1–2 |
| 3 | 2×2 mesh (12 unknowns): A, eigenvalues, κ, direct solvers | §4 |
| 4 | 20×20 mesh (840 unknowns): 8 solvers under one protocol | §3–4 |
| 5 | Refinement 10/20/40: κ ~ h⁻², CG iterations ~ √κ | §4 |
| 6 | Validation: equilibrium, exact solution, perturbation | §4 |
| 7 | Square, 2×1 rectangle, square with an opening (Triangle meshes); geometry, mesh, load-magnitude, load-location and support studies; acceptance checks; full solver protocol | §5–6 |
| 8 | Export of all results and figures to `outputs/` | |
| 9 | Summary derived from the exported results | §6–7 |

## Running it

```sh
pip install numpy "scipy>=1.12" matplotlib triangle jupyter
jupyter nbconvert --to notebook --execute --inplace notebook/Group02_Notebook.ipynb
```

You can also open it in Jupyter and choose *Run All*. The first cell installs `triangle` if it is missing. A full run takes about 8–10 minutes on a laptop. Most of that is the eight-method solver protocol on every Part 7 case; set `FULL_PROTOCOL = False` in Part 7 for a quick CG/PCG-only run.

Tested with Python 3.12 using two setups: NumPy 1.26 / SciPy 1.13 / Matplotlib 3.9 / triangle 20250106, and NumPy 2.5 / SciPy 1.18 / Matplotlib 3.11. The versions of each run are recorded in `outputs/results/manifest.json`.

## Inputs

- The Part 7 case specification is `draft/sections/05-objects-and-experiments/cases.json` at commit `2b23fd5` (merged PR #7). It is embedded in the notebook, so the notebook needs no other file.
- Triangle can produce slightly different meshes on different platforms. The meshes behind the committed results are stored in `outputs/meshes/*.npz`, with SHA-256 fingerprints in `outputs/results/objects_meshes.csv`. The notebook reuses them when they are present. Set `REGENERATE_MESHES = True` to mesh again.

## Outputs (`outputs/`)

| File | Content |
|---|---|
| `results/objects_cases.csv` | one row per Part 7 case: observables (m), algebraic estimates, λ/κ with status, CG/PCG status, every acceptance check |
| `results/objects_solvers.csv` | 8-method protocol per case: iterations, native status, true residual, accepted, error vs LU, best time |
| `results/objects_mesh_differences.csv` | successive-mesh differences (signed and absolute), resolved / unresolved / unverified |
| `results/objects_meshes.csv`, `meshes/*.npz` | exact meshes and their quality |
| `results/structured_*.csv`, `structured_validation.json` | Parts 3–6 (structured meshes; keep separate from Part 7) |
| `results/manifest.json` | environment, specification source, definitions, thresholds, outcome counts |
| `figures/*.png` | all figures |

Timings depend on the machine. Displacements and acceptance outcomes agree across both tested setups. Iteration counts can differ by ±1 between library versions because of rounding (for example, CG on the rectangle takes 427 iterations with SciPy 1.13 and 426 with SciPy 1.18). The committed outputs come from the NumPy 1.26 / SciPy 1.13 run.
